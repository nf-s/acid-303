Fluff drum samples

Every file in fluff/ is CC0 1.0 (licenses/CC0-1.0.txt).

Recorded sources:
- Sonic Pi sample library, https://github.com/sonic-pi-net/sonic-pi/tree/main/etc/samples
  (kick-click, kick-round, kick-deep, kick-tight, kick-boom, clap-snap)
- Virtuosity Drums by Versilian Studios and Karoryfer Samples,
  https://github.com/sfzinstruments/virtuosity_drums
  (kick-acoustic, kick-lofi, snare-break, snare-dusty, snare-ghost, snare-room,
  perc-rim, perc-tom, perc-conga, perc-crash)

Synthesized for this project and released under CC0 1.0: every hat-* file,
snare-house, snare-garage, snare-roll, clap-house, clap-tight, clap-hall,
clap-dusty, clap-layered, clap-soft and perc-tamb.

Per-file sources, edits and synthesis are listed in docs/samples.md in the source repository.
